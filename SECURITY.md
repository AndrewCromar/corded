# Security

## Current state

Corded is pre-alpha. There is no released code, and nothing in this repository has been
reviewed or audited by an independent party. Treat every design document here as a
proposal, not a guarantee.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private vulnerability reporting for this repository
(Security tab, "Report a vulnerability"). Include what you found, how to reproduce it and
what you think the impact is. You should get an acknowledgement within a week.

Design-level concerns about the protocol or threat model are welcome as ordinary issues,
since the design is public and still changing.
